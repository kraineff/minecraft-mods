# Стиль Java

Обязательное — в `.claude/rules/code.md`; здесь — приёмы и детали. Формат сверяет Checkstyle, связи — `scripts/checks` (скилл `checks`).

## Именование

| Что | Как | Пример |
|---|---|---|
| Классы, record | `PascalCase`, по смыслу, без `Manager`/`Helper` | `HorseTracker`, `GrowthTracker`, `HorseInfo` |
| Константы (`static final`, неизменяемое) | `UPPER_SNAKE` | `TRACK_RADIUS`, `FOOD_SECONDS` |
| Изменяемое состояние (`static`, коллекции-кеши) | `camelCase` | `estimates`, `labels` |
| Логгер | `log` — первое поле класса | `private static final Logger log = …` |
| Обработчик миксина | `<id>$глагол…` | `stallium$glowBestHorse` |
| Ключ перевода | `<категория>.<id>.<имя>` | `screen.stallium.show_bars` |

## Устройство мода

- Пакеты по смыслу: `config/` (настройки и экран), `render/` (рендер и HUD), `stats/` или своя предметная область (расчёты и состояние), `compat/` (различия целей), `mixin/` (только миксины).
- Тик считает, рендер читает: тяжёлое (поиск сущностей, расчёты, строки `Component`) — раз в тик в своём классе, рендер берёт готовое. Никаких аллокаций и поиска в коде кадра сверх необходимого.
- Значения — `record` с производными методами (`HorseInfo.speedBps()`), без сеттеров.
- Утилиты — `final` класс с закрытым конструктором; без синглтонов, где хватает статических методов.
- Формулы ванили — с именем ванильного метода и источником в комментарии (`AbstractHorse.createOffspringAttribute`, ru.minecraft.wiki): по ним сверяют расчёт при новой версии.

## Комментарии

- По-русски, о «почему»: формула и её источник, ограничение API, в какой версии поменялось поведение, обход бага.
- Javadoc — на классах (что делает и как устроено) и на неочевидных методах; на геттерах и очевидном — нет.
- Нельзя: пересказ строки, следы задач (`// fix #12`), закомментированный код.

## Null, ошибки, конфиг

- `@Nullable` из jspecify — на полях и возвратах, которые бывают null; остальное считается не-null.
- Рефлексия не нашла ни одного варианта — `IllegalStateException` с текстом, что искали; вызов упал — тоже с причиной.
- Ввод-вывод конфига — `warn` с причиной и значения по умолчанию, игра не падает; значения ограничиваются (`Math.clamp`) при чтении и записи.

## Формат

- Табы; перенос строки — на два таба глубже начала выражения; операторы `&&`, `||`, `?`, `:` — в начале перенесённой строки.
- Скобки у `if`/`for`/`while` — всегда; ранний `return` вместо вложенности.
- Импорты — одним блоком по алфавиту, без `*`; статические — отдельным блоком сверху.
- `var` — когда тип виден справа или очевиден; в публичных сигнатурах — явные типы.
