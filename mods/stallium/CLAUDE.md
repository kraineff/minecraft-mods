# Stallium

Клиентский мод про лошадей: статы над каждой лошадью в радиусе (скорость, прыжок, здоровье — полоски и числа), золотая обводка лучшей рядом, HUD своей лошади верхом, подсказка пары для разведения и таймер роста жеребят. На сервер не ставится, работает на любых серверах. Возможности для людей — `README.md`; там же дерево пакетов («Как устроено») — при новом классе дописывать туда.

Общие правила — корневой `CLAUDE.md` и `.claude/rules/`; здесь — только то, что свойственно моду.

## Как устроено

- **Тик считает, рендер читает.** `HorseTracker.tick` раз в клиентский тик собирает лошадей в радиусе, выбирает лучшую и пару, строит готовые строки `Component`; `HorseLabels` (надписи через `submitNameTag`) и `HorseHud` (строка над хотбаром) только их рисуют.
- **Лучшая** — сводный балл: скорость 45 %, прыжок 35 %, здоровье 20 %, нормировка по диапазонам генерации `AbstractHorse` (`HorseInfo`). Обводка: не верхом — у лучшей, если есть из чего выбирать; верхом — только у той, что заметно лучше нашей.
- **Пара для разведения** — матожидание статов жеребёнка по ванильной `createOffspringAttribute` с отражением за границей диапазона (`Breeding`, квадратура по плотности Ирвина — Холла); только внутри вида, мулы бесплодны.
- **Таймер роста** (`GrowthTracker`): в одиночной игре — точный, из встроенного сервера; на серверах возраст клиенту не приходит — оценка от увиденного рождения минус свои кормления, пока сущность выгружена — время стоит.
- **Числа в блоках**: скорость бл/с = атрибут × 43, прыжок — симуляция ванильной физики, здоровье 15–30; совпадает с ru.minecraft.wiki.
- **Иконка таймера** — свой глиф U+E000 шириной 6 px (`assets/stallium/font/icons.json`): ванильные ⌛ шире ♥⚡↑, и колонки разъезжались.
- **Обводка** — миксины `MinecraftMixin` (`shouldEntityAppearGlowing`) и `EntityMixin` (`getTeamColor`, золотой; команду игрока уважает).

## Совместимость целей

`compat/ScreenCompat` (открыть экран: 26.1 — `Minecraft.setScreen`, 26.2+ — `Gui.setScreen`) и `HorseLabels` (`submitNameTag` с `distanceToCameraSq` в 26.1 и без него с 26.2) ищут сигнатуры через MethodHandle; gametest так же ищет ожидание чанков (`getClientLevel` до 26.3, `getConnection` с 26.3). Список различий — `porting.md` скилла `fabric`.

## Проверка

Скриншот-тест `StalliumGameTest`: плоский мир, три взрослые лошади с разными статами и жеребёнок на половине роста; снимки — поле, поле с Shift, жеребёнок, он же с Shift, верхом, экран настроек. После правок рендера, HUD, экрана или `compat/` — `./gradlew -p mods/stallium runClientGameTest -PtargetMc=<цель>` под первой и последней целью и посмотреть снимки; для README и галереи — `updateScreenshots`.
